# Ommatidia

AIが自分の理解を確かめ、見えていない観点の候補に気づき、次に必要な探索を組み立てる仕組みを研究する。

**現在は研究計画と論文下書きの段階。実装、実験結果、学術的な新規性は未確定。**

中心となる問いは「既知の道を繰り返し通るだけでなく、現在の理解を変え得る方向へ探索を向けることで、同じ予算でも調査の結果を改善できるか」である。

## TOMBOとの関係

TOMBOは、AIの主張と根拠を点検し、未確認事項と検査方法を返す設計である。Ommatidiaでは、その検査から探索役を構成し、取得した証拠を照合して理解を更新する部分を研究する。

探索役を増やすだけでは効果と見なさない。同じ情報源の転載を複数の役が見つけても、独立した証拠として数えない。過去の成功回数だけで探索経路を優先し続ける設計は採用しない。

## 最初に進めること

1. 先行研究の本文と原実装を確認し、重なる部分と異なる部分を整理する。
2. 一般的な再点検、固定観点、単独の適応探索との比較条件を固定する。
3. 小さな試験環境を実装して測定する。
4. 結果に従って、論文の主張と設計を更新する。

論文の本文は実際の記録から書く。実験を行っていない段階では、効果や数値を補わない。
